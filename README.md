## ข้อกำหนดเบื้องต้น

- ความรู้พื้นฐานเกี่ยวกับคอมพิวเตอร์
- ความสามารถในการใช้งาน Terminal/Command Line เบื้องต้น
- ไม่จำเป็นต้องมีประสบการณ์การเขียนโปรแกรม

## เครื่องมือที่ต้องการ

- **Compiler**: GCC 9+ หรือ MSVC 2019+
- **Qt Framework**: Qt 6.5+ (แนะนำ) หรือ Qt 5.15+
- **IDE**: Qt Creator (แนะนำ), VS Code, CLion, Visual Studio
- **OS**: Windows 10+, macOS 10.14+, Linux Ubuntu 20.04+
